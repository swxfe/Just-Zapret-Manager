`strategies.txt` — текстовые параметры nfqws из исходного менеджера: v / Dv /
Yv / Gv. Сборщик встраивает их непосредственно в константу ucode. Текстовые
ресурсы этого каталога доступны без распаковки файлов.

`sources.json` задаёт источники стратегий, релизов, игровые порты и aliases fake.
Каталоги загружаются на конкретном commit SHA и сохраняются в `/etc/zapret-manager`.
BAT разбирается как данные. Fake-файлы скачиваются при применении стратегии;
они не кодируются и не распаковываются из сборки.

`network.json` задаёт nft-таблицу, цепочку и метку исключений устройств.
`urls.txt` — URL тестов по умолчанию; в меню их можно выбрать как `@default`.
`google.txt` и `exclude.txt` создают отсутствующие списки при установке Zapret.

`manager.json` — встроенная конфигурация менеджера. При установке её начальная
копия записывается в `/etc/zapret-manager/manager-config.json`.
