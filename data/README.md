В этом каталоге находятся собственные настройки JZM.
`manager-strategies.txt` сохраняет исходные игровые профили каталога Manager.

`just dist` собирает чистый код `dist/Zapret-Manager.sh` (также
`dist/just-zapret-manager.sh`) и отдельный `dist/jzm-assets.tar.gz`.

Сборщик `tools/build-assets.py` получает фейки и списки только из
Flowseal/zapret-discord-youtube, закрепляя ревизию источника:

- бинарные фейки из `bin/`, включая точные ACTIVE-файлы;
- готовые пресеты и группы base / YouTube / Discord / games из `general*.bat`;
- списки general, Google и exclude из `lists/`;
- HTTP/HTTPS-адреса проверок из `utils/targets.txt`.

Стратегии Zapret Manager также включены: сборщик читает только определения
из `Zapret-Manager.sh`, `files/StrYoutube` и сохранённые игровые профили.
Скрипты источника никогда не исполняются. Все пути фейков ведут в
`/opt/zapret/fakes/`. Пресеты с отсутствующими в Flowseal файлами сохраняются
в каталоге с явной отметкой недоступности; подмена бинарников не выполняется. Для `4pda.bin` используется
побайтно совпадающий файл Flowseal `tls_clienthello_4pda_to.bin` с исходным именем.

Настройки JZM и nft берутся из локальных `manager.json` и `network.json`.
Сборщик определяет ревизию через `git ls-remote` и получает архив именно этой
ревизии с GitHub; REST API и его лимит запросов не используются. Импорт BAT
выполняется только на сборочном компьютере.
Не поддерживаемые при переносе пресеты перечисляются в выводе сборки и каталоге.
Если нужный .bin отсутствует, сборка завершается ошибкой без подмены файла.

Архив содержит манифест с размерами и SHA256. На роутере `ucode` проверяет
содержимое и публикует его внутри транзакции, а BusyBox `tar` распаковывает файлы.
Каталоги, списки и манифест находятся в `/etc/zapret-manager/assets/`,
фейки — в `/opt/zapret/fakes/<исходное_имя>.bin`. В архиве для них
есть только `fakes/`, без дубликатов defaults и хешей в именах. Работа оффлайн.
Для обновления данных нужно установить архив нового релиза.
